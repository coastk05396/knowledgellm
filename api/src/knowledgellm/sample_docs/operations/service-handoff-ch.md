# Northstar 維運部 — 輪班交接與服務持續運作

> 供公開展示使用的虛構範例；並非真實公司資料或政策。

## 1. 輪班時程與交接時間
為確保 24/7 服務不中斷，維運輪班遵循結構化的交接流程：
- **亞太交接至歐洲、中東與非洲**：08:00 UTC（16:00 SGT）
- **歐洲、中東與非洲交接至美洲**：14:00 UTC（10:00 EST）
- **美洲交接至亞太**：22:00 UTC（06:00 SGT）

## 2. 必要交接檢查清單
完成輪班移交前，交班協調員須在輪班看板記錄下列欄位：
- **處理中的工單**：所有尚未結案的 P1/P2/P3 工單，以及目前進度與阻礙摘要。
- **系統健康狀態**：雲端服務狀態、API 錯誤率（必須為 `< 0.05%`）及資料庫 CPU 使用率。
- **進行中的部署**：Canary 發布版本、部署進度及回復決策期限。
- **排定的維護**：下一班期間預定進行的任何基礎設施維護時段。
- **主要聯絡人**：當班的主要值班工程師及升級聯絡人。

## 3. 維護時段規範
- 標準例行維護時段為 **每週二及週四 02:00 至 04:00 UTC**。
- 正式環境變更須具備書面變更申請工單，並至少提前 24 小時取得維運主管核准。
