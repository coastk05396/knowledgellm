# Northstar 人才部 — 員工手冊與職場文化

> 供公開展示使用的虛構範例；並非真實公司資料或政策。

## 1. 歡迎與公司文化
歡迎加入 Northstar！我們重視包容與高度信任的環境，讓分散式協作及創意問題解決能夠蓬勃發展。

## 2. 彈性與混合工作政策
- **核心協作時段**：以您的主要時區計算，為 10:00 至 15:00，以利跨部門會議。
- **遠端工作**：團隊成員可在主管同意下，採遠端工作、於 Northstar 據點辦公室工作或混合工作模式。
- **居家辦公補助**：提供一次性最高 **500 點**的設備報銷，用於符合人體工學的桌面設備及周邊用品。

## 3. 學習與發展（L&D）福利
- **年度教育預算**：每位全職員工每年可獲得 **1,000 點**，用於專業課程、書籍、技術研討會或認證。
- **申請流程**：透過內部人才入口網站提出申請，取得主管簡易簽核即可。

## 4. 硬體與資訊安全標準
- 筆記型電腦每 **36 個月**更新一次。
- 必須使用全磁碟加密（FileVault／BitLocker）及 1Password 密碼管理工具。
- 所有公司工具及電子郵件帳號皆須啟用多因素驗證（MFA）。

## 5. 支援與道德諮詢專線
若您遇到職場爭議、安全疑慮或法遵問題，請透過 `people-help@northstar.internal` 保密聯絡。
