# Northstar 人才部 — 休假政策

> 供公開展示使用的虛構範例；並非真實公司資料或政策。

## 1. 概覽
Northstar 重視休息與工作生活平衡。我們提供完整的有薪休假選項，以支持個人身心健康、家庭責任及突發緊急狀況。

## 2. 年度特休
- **可享天數**：全職員工每個日曆年累積 **20 天有薪特休**（每月累積 1.67 天）。
- **結轉**：最多可將 **5 天未使用的特休**結轉至下一個日曆年的第一季。
- **提前通知期限**：休假超過連續 3 天時，請至少提前 **5 個工作日**提交特休申請。

## 3. 病假與健康假
- **可享天數**：每年有 **10 天有薪醫療假**，可用於生病、心理健康或預防性醫療就診。
- **醫療證明**：僅在連續因醫療因素缺勤超過 **2 天**時，才須提供合格醫師證明。

## 4. 育兒與家庭照顧假
- **主要照顧者**：生育、收養或安置寄養兒童後，可享有 **16 週全薪休假**。
- **次要照顧者**：可於孩子出生後的前 12 個月內使用 **6 週全薪休假**。
- **慰問假**：因喪親或家人發生嚴重醫療緊急狀況，最多可享有 **5 天有薪休假**。

## 5. 國定假日
Northstar 依照您合約所屬地區遵守所有官方國定假日。每年會在人才入口網站公布地區假日時程。
