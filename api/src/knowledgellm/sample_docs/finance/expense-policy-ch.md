# Northstar 財務部 — 公司費用報銷政策

> 供公開展示使用的虛構範例；並非真實公司資料或政策。

## 1. 概覽與政策適用範圍
本政策說明 Northstar 團隊成員可報銷的業務費用。所有費用皆須為代表公司支出的合法、合理且必要的業務成本。

## 2. 收據要求與提交期限
- **必要收據**：任何單筆超過 **25 點**的費用，皆須附上詳細列明項目的收據。
- **提交期限**：費用報告須於交易日起 **14 個日曆日**內提交至財務入口網站。
- **信用卡對帳**：每月公司信用卡帳單須於次月 5 日前完成對帳。

## 3. 差旅與餐費規範
- **餐費額度**：因公出差時，每日餐費上限如下：
  - 早餐：最高 **20 點**
  - 午餐：最高 **35 點**
  - 晚餐：最高 **65 點**
- **航班**：飛行時間少於 6 小時的國內及區域航班，必須搭乘經濟艙。商務艙須事先取得副總裁核准。
- **住宿**：標準商務旅館費用上限為 **200 點／晚**。須至少提前 14 天訂房。

## 4. 核准門檻
- **低於 500 點**：須由直屬主管核准。
- **500 至 2,500 點**：須由部門主管／總監核准。
- **超過 2,500 點**：須由財務副總裁簽核。

## 5. 不可報銷的費用
公司不報銷個人美容、交通／停車違規罰款、航班升等或個人休閒娛樂費用。
