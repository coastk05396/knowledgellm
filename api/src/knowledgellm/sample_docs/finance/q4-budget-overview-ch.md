# Northstar 財務部 — 第四季營運預算概覽

> 供公開展示使用的虛構範例；並非真實公司資料或政策。

## 1. 執行摘要
Northstar 財務領導團隊已在供應商合約協商及年中績效檢討後，完成第四季營運預算修訂。本季核准的營運支出總額為 **108,000 點**。

## 2. 部門預算分配
- **工程與平台**：45,000 點（雲端運算、CI/CD 執行器、可觀測性）
- **行銷與成長**：25,000 點（活動廣告支出、品牌設計、客戶開發）
- **維運與支援**：18,000 點（24/7 監控工具、事件應變軟體）
- **人才與文化**：12,000 點（學習補助、招募工具、團隊外出活動）
- **一般與行政**：8,000 點（法遵、保險、會計稽核）

## 3. 應急準備金與差異分析
- **應急準備金**：保留已核准的 **8,000 點**準備金，以因應供應商意外漲價或緊急基礎設施擴充。
- **授權費用差異**：SaaS 軟體授權費較第三季增加 **3,200 點**（+7.2%）。
- **已實現的節省**：整併企業合約達成每年 **4,500 點**的節省。

## 4. 人力與規劃調整
- 原定於第四季末新增的人力，已策略性移至第一季規劃週期。
- 非必要的承包商支出，須在簽訂合約前取得財務部事先核准。
