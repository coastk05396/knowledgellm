# KnowledgeLLM — System Prompt & Product Requirements Specification

## 1. Project Overview & Mission

**KnowledgeLLM** is an enterprise-grade, permission-aware internal AI knowledge assistant prototype. It enforces strict zero-trust role-based access control (RBAC) across corporate departments, ensuring authenticated users can only search, browse, and retrieve answers from documents their department is explicitly authorized to view.

All answers generated by the AI assistant cite only permitted, retrieved source documents with verifiable citation links. Unauthenticated users or unauthorized departments cannot access, view metadata, or infer document contents.

## 3. User Experience & Core Journeys

### 3.1 Seamless 1-Click Persona Authentication
* **Background Direct Auth**: Tapping a persona card (Alex, Sam, or Priya) in the brand header authenticates directly against Amazon Cognito via `USER_PASSWORD_AUTH` in the background (~200ms) with zero pop-up credential prompts.
* **Instant Toast Feedback**: A floating toast notification pops up confirming login success (e.g., `Alex signed in successfully · Finance folder unlocked`).
* **Session Persistence**: Sessions persist in `sessionStorage` across page reloads.

### 3.2 Department Folders & File Navigation
* **Permission Locks**: Unauthorized department folders display a lock icon (`LockKeyhole`) and are disabled.
* **Automatic Unlocking Across All Personas**:
  - When clicking **Sam** (`operations`), the lock icon on the Operations folder MUST disappear, revealing the document count badge (e.g., `2`), and the folder must auto-expand with operations files (`Runbook & procedures`, `Service handoff`).
  - When clicking **Alex** (`finance`), the lock icon on the Finance folder MUST disappear, revealing the document count badge (e.g., `2`), and the folder must auto-expand with finance files (`Q4 budget overview`, `Expense policy`).
  - When clicking **Priya** (`people`), the lock icon on the People folder MUST disappear, revealing the document count badge (e.g., `2`), and the folder must auto-expand with people files (`Employee handbook`, `Leave policy`).
* **Dynamic State Transition**: When switching from one persona to another, the previous department folder re-locks with the lock icon, while the newly authenticated persona's folder unlocks instantly without requiring a page refresh.
* **Accordion Controls**: Users can click the unlocked folder header to extend or collapse the file list at any time.
* **Document Inspection**: Clicking a document opens a presigned, short-lived S3 view URL in a secure tab.

### 3.3 Grounded Cited Chat & Guardrails
* **Scoped Questions**: Users query the LLM using the bottom composer.
* **Zero Cross-Department Leakage**: Vector search queries Qdrant with mandatory department metadata filters (`filter: department == user_department`).
* **Cited Answers**: Answers strictly cite returned chunks with clickable citation badges linking to source files.
* **Guardrails**: Server-side PII redaction and refusals for out-of-scope or ungrounded questions.
* **System Monitor**: Live cost calculation and token consumption tracking displayed on desktop sidebar and mobile accordions.

### 4.1 Frontend Stack
- **Framework**: React 19, TypeScript, Vite 7.
- **Styling**: Vanilla CSS with custom design tokens (`IBM Plex Sans`, `IBM Plex Mono`).
- **Icons**: `lucide-react`.
- **Testing**: Vitest, React Testing Library.

### 4.2 Backend Stack
- **Runtime**: Python 3.12 (AWS Lambda).
- **Libraries**: `boto3`, `qdrant-client`, `fastembed`, `groq`.
- **Embeddings**: `sentence-transformers/all-MiniLM-L6-v2` (FastEmbed CPU).
- **LLM**: Groq Cloud (`llama-3.3-70b-versatile` or `llama-3.1-8b-instant`).

### 4.3 Cloud Infrastructure (Terraform)
- **Tool**: Terraform / OpenTofu under `infra/terraform/`.
- **State**: Remote S3 backend in `ap-southeast-1`.
- **Operating Target Cost**: Strict **$0.00 / month (AWS Free Tier)**.

## 5. Security & Zero-Cost Mandates

1. **Zero Trust Authorization**: The Python Lambda API decodes API Gateway authorizer claims directly (`cognito:groups`) and never trusts client-supplied department parameters.
2. **Never Commit Secrets**: Secrets reside in AWS Systems Manager (SSM) Parameter Store standard `SecureString` parameters ($0.00) rather than AWS Secrets Manager ($0.40/mo).
3. **Short Log Retention**: CloudWatch Log Groups have a 7-day retention limit to prevent unbounded storage costs.
4. **Serverless Only**: No persistent EC2 instances, containers, NAT Gateways ($32/mo), or Application Load Balancers ($16/mo).
5. **API Gateway Authorizer Rule**: Never configure `authorization_scopes = ["openid"]` on routes protected by Cognito Access Tokens.
